# Rent A Car

Rent A Car is a Laravel-based script designed for vehicle rental systems.  
This application allows you to manage unlimited vehicles, rental settings, and related configurations from an admin panel.

---

## Getting Started

Rent A Car helps you build and manage a complete vehicle rental system with ease.

---

## Server Requirements

- Laravel >= 10.0
- PHP >= 8.1.0
- BCMath PHP Extension
- Ctype PHP Extension
- cURL PHP Extension
- DOM PHP Extension
- Fileinfo PHP Extension
- JSON PHP Extension
- Mbstring PHP Extension
- OpenSSL PHP Extension
- PCRE PHP Extension
- PDO PHP Extension
- Tokenizer PHP Extension
- XML PHP Extension

---

## Installation

### Pre-installation Requirements

#### File System Permissions

Ensure the following directory is writable:

storage/

Set permission to `777` for the storage directory and all its subfolders.

---

### Database Setup

1. Create a database (example: `rental_system`)
2. Upload the project files to your server

---

## Installation Steps

### Step 1 – Welcome Screen

yourdomain.com/install

Ensure the `.env` file exists in the project root.

If yourdomain.com/install does not work but  
yourdomain.com/public/index.php/install does, enable Apache mod_rewrite.

---

### Step 2 – System Requirements

The installer will check all required PHP extensions.

---

### Step 3 – Directory Permissions

Ensure required directories are writable.

---

### Step 4 – Environment Setting

Configure application environment values.

---

### Step 5 – Database Setting

Enter database credentials.

---

### Step 6 – Exit

Finish installation and start using the system.
